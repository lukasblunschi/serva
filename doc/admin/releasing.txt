Releasing Serva Howto
---------------------

1. update changelog.txt

2. update upgrade.txt

3. increase version number in:
   - src/main/java/ch/serva/ServaConstants.java
   - war/WEB-INF/web.xml
   - build.gradle.kts

4. commit "releasing ..."

5. create git tag

6. build WAR
   - run Gradle
     $ ./gradlew clean assemble
   - check the generated WAR file
     -> see doc/notes/entries-in-howto-recreate.txt

7. upload to github release page
   - using web interface
