How to recreate the lists of entries in the WAR and JAR files:

1. Build the WAR file as described in the README.md:

   $ cd /path/to/serva
   $ ./gradlew clean assemble

2. Extract the lists of entries in the WAR and JAR files:

   - set version number
     $ version=0.3.1

   - entries in WAR
     $ unzip -Z -1 build/libs/serva-$version-repacked.war \
         | sort > doc/notes/entries-in-war.txt

   - entries in JAR
     $ unzip       build/libs/serva-$version-repacked.war \
                     WEB-INF/lib/serva-$version.jar && \
         unzip -Z -1 WEB-INF/lib/serva-$version.jar \
         | sort > doc/notes/entries-in-jar.txt &&
         rm -rf WEB-INF
